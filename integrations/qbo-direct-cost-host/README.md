# QBO host: closed-month pricing

`whole-entry-priority.patch` follows `skipped-qbo-priority.patch`. Existing receipt-bound Screeding, Trucking, and Subcontractor entries that differ from the automatic source are retained as complete live QBO entries, rather than repriced using Procore quantities. Recognized screeder/.LS sources, Trucking/Dump Truck/Hauling descriptions, and explicit subcontractor types/.S products, labels or the five configured trade codes qualify; employee timecards and Food do not. Names classify categories only: saved source bindings establish QBO identity. Missing bound entries stay absent; unbound new sources follow ordinary validation. Durable `qboEntryPreservedKeys` keeps preservation across later saves. Mixed protected/ordinary ownership, wrong project identity, payments and unbalanced bills remain blocked. Exclusively retained offsets keep their live values; shared offsets retain the QBO contribution while unrelated automatic work can change. Queue status replays successful receipt evidence offline; prepare/post reread QBO and keep version checks. A metadata-only confirmation uses the existing no-write path when QBO already matches.

Run `node --test` in the patched host, including `test/qbo-entry-priority.test.js`, then deploy to the idle host before the matching Analytics display. The UI separates retained QBO entries from automatic items. No historical receipt repair, automatic batch run, new schema, or QBO business-record write is part of deployment. Apply/reverse-check and restart using the existing procedure below.

`skipped-qbo-priority.patch` follows `skipped-lines.patch`. Skipped receipt-bound charges and their QBO replacements retain their exact live values and category lines, including offsets with edited or absent descriptions. An old offset can be released only when every receipt-bound contributor is skipped; shared active offsets keep their checks. Manually entered category lines remain additions, never matched to automatic sources by name. The complete live bill must still balance, active item/offset ownership remains checked, and a prior reconciliation cannot discard the skipped replacement. Regression tests cover both reconciliation states, repeated updates, an unchanged bill with no QBO write, shared offsets, invalid active identity, and real imbalance. Apply and restart the idle host using the procedure below; validate all 154 host tests, then use read-only prepare and reconciliation-preview for the affected bill. No receipt repair, migration, or automatic bill rewrite is required.

The host freezes existing source-line unit rates for months before the current Eastern calendar month. Its baseline is the receipt-matched successful attempt/revision, including output grouping and retained QBO rates. Source keys establish identity; product names do not. Manual additions are excluded using saved QBO line IDs. Existing manual QBO price/class handling is preserved. Food totals, new source lines, and quantity changes remain reviewable. First-time historical bills use current rates because no saved bill price exists. Missing or ambiguous history blocks repricing. Existing source, catalog evidence and freshness validation remain in force.
